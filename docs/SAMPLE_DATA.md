# サンプルデータ例

このファイルは、アプリケーションが生成する CSV ファイルの例です。
実際にはアプリケーションが自動で作成するため、手動で作成する必要はありません。

## household_data.csv の構造

```csv
AccountID,TransactionID,Date,Category,Amount,Description
default_account,TXN1701234567890,2025-11-01,収入,300000,給与
default_account,TXN1701234567891,2025-11-05,食費,3500,スーパーでの買い物
default_account,TXN1701234567892,2025-11-10,交通費,2000,電車代
default_account,TXN1701234567893,2025-11-15,住居費,80000,家賃
default_account,TXN1701234567894,2025-11-20,光熱費,12000,電気・ガス代
default_account,TXN1701234567895,2025-11-22,娯楽,5000,映画鑑賞
default_account,TXN1701234567896,2025-11-25,食費,4200,外食
default_account,TXN1701234567897,2025-11-28,医療費,3000,薬代
```

## フィールドの説明

| フィールド    | 説明                      | 例                                                       |
| ------------- | ------------------------- | -------------------------------------------------------- |
| AccountID     | アカウント ID             | default_account                                          |
| TransactionID | 取引の一意な ID           | TXN1701234567890                                         |
| Date          | 取引日（YYYY-MM-DD 形式） | 2025-11-01                                               |
| Category      | カテゴリ（日本語）        | 収入, 食費, 住居費, 交通費, 娯楽, 光熱費, 医療費, その他 |
| Amount        | 金額（円）                | 300000                                                   |
| Description   | 説明                      | 給与                                                     |

## 注意事項

- CSV ファイルは実行ファイルと同じディレクトリに作成されます
- 初回実行時に自動でヘッダー行が作成されます
- データは追記ではなく、アカウント単位で上書きされます
- 文字エンコーディングはシステムのデフォルト（通常は UTF-8 または Shift-JIS）
